# Wanderbound

Wanderbound turns Polarsteps ZIP exports into editable, print-ready photo
albums. It is a FastAPI and Vue 3 monorepo.

## Working in this repository

- Run repository tasks with `mise run <task>`. Use `mise tasks` for the current
  command list.
- Prefer less code. Use builtins, existing dependencies, and platform features
  before adding abstractions or packages.
- For dependencies, architecture, external APIs, standards, and tooling,
  verify current official documentation and practitioner usage before changing
  direction.
- Surface unrelated problems, but fix them only when they block the task, are
  in touched code, or the user approves broader cleanup.
- Never edit `frontend/src/client/`. It is generated by
  `@hey-api/openapi-ts`.
- Never commit generated planning or workflow artifacts such as
  `docs/superpowers/` or `.superpowers/`.

## Product invariants

- Album pages are A4 landscape, 297 by 210 mm.
- Editor preview and PDF output must render the same album visuals. Print mode
  may hide editor controls, but must not change album content or layout.
- Processing-session SSE reconnects replay stored events. They do not restart
  processing.

## Tests and scoped guidance

- Add tests only for a distinct, high-impact failure that existing retained
  tests cannot detect. Read `.claude/rules/testing.md` before changing tests.
- Read `.claude/rules/print-safe.md` for album or PDF-facing CSS changes.
- Read `frontend/DESIGN.md` for visual design work.
